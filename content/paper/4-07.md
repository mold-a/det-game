Осмотр проведён для проверки показаний {{ c.volkov.short('gen') }}, данных при опросе 10.11.2026, о том, где {{ c.volkov.g('он находился', 'она находилась') }} во время спектакля «{{ w.play.title }}».

Перед началом осмотра {{ c.volkov.short() }} {{ c.volkov.g('пояснил', 'пояснила') }}: «Это та самая запись, которую я {{ c.volkov.g('показывал', 'показывала') }} вечером десятого. {{ c.volkov.g('Снимал', 'Снимала') }} в репетиционном зале на третьем этаже, пока {{ c.volkov.g('дежурил', 'дежурила') }} на премьере, — {{ c.volkov.g('гонял', 'гоняла') }} текст роли на случай, если придётся выходить вместо {{ c.voroncov.io('gen') }}. Смотрите сколько угодно, мне скрывать нечего».

В ходе осмотра установлено: телефон исправен, включён, экран разблокирован владельцем. В приложении «Галерея» по указанию владельца открыт видеофайл, который, со слов {{ c.volkov.short('gen') }}, {{ c.volkov.g('он предъявлял', 'она предъявляла') }} 10.11.2026. На записи {{ c.volkov.short() }} в сценическом костюме читает текст роли; длительность — менее одной минуты.

Видеофайл скопирован без изменений, с сохранением свойств файла, на носитель следственной группы и загружен в систему «{{ w.brands.system }}», раздел «Изъятые файлы». Для просмотра копии — QR-код на этом листе. Иные файлы и данные телефона не осматривались.

{{ c.volkov.short() }} {{ c.volkov.g('попросил', 'попросила') }} не задерживать телефон: «Мне на нём роль учить». По окончании осмотра телефон возвращён владельцу. Заявлений и замечаний от участвующих лиц не поступило.
