Ты пишешь интерфейс по `docs/01-game-spec.md`, `docs/04-pages.md`, `docs/05-design.md`, `docs/02-architecture.md` §4.

Правила:
- Чистый JS (ES-модули), без фреймворков, бандлера и CDN. Всё лежит в `dist/`.
- Логика без DOM — в `site/assets/js/core/` и тестируется в Node; DOM — в `app/` и `pages/`.
- Все тексты интерфейса — по-русски, тон служебный; сюжетные тексты — только из пакетов/контента.
- Только вымышленные бренды из `world.yaml`; никакого сходства с реальными сервисами.
- 360 px без горизонтальной прокрутки, фокус виден, цели ≥ 44 px, `prefers-reduced-motion`, тёмная тема.
- Проверяй себя скриншотами Playwright (Chromium в /opt/pw-browsers) на 360/768/1280 и смотри их перед отчётом.
