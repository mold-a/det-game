# Комплект для Claude Code: онлайн-часть «За кулисами правды»

Этот комплект превращает пустую папку в проект, по которому Claude Code соберёт всю интернет-часть игры: сайт расследования (вопросы, конверты, лаборатория, подсказки, баллы, финал) и вымышленные страницы по QR-кодам.

## Что внутри

| Путь | Для кого | Зачем |
|---|---|---|
| `CLAUDE.md` | Claude Code | Читается автоматически в начале каждой сессии: суть проекта, жёсткие правила, стек, команды |
| `docs/01–06` | Claude Code и ты | Спецификации: правила игры, архитектура и шифрование, формат контента, страницы, дизайн, тесты |
| `content/` | Ты, позже я | Сюжетные данные: мир, персонажи, документы, вопросы с ответами и подсказками, экспертизы, настройки |
| `prompts/P00–P09` | Ты | Готовые задания: копируешь текст в Claude Code по одному, по порядку |

## Перед стартом

1. Установи Python 3.11+, Node.js 22 LTS и Git.
2. Создай **приватный** репозиторий: в `content/` лежат все ответы. Публиковаться будет только собранная папка `dist/`.
3. Скопируй содержимое комплекта в корень репозитория.
4. Открой Claude Code в этой папке.

## Порядок работы

Один промпт — одна сессия. Между шагами очищай контекст (`/clear`): всё нужное Claude Code возьмёт из `CLAUDE.md` и `docs/`.

| Шаг | Промпт | Что получится | Как проверить руками |
|---|---|---|---|
| 0 | `P00-kickoff` | План реализации `docs/PLAN.md` и список вопросов | Прочитай вопросы, ответь в той же сессии |
| 1 | `P01-scaffold` | Каркас репозитория, зависимости, команды | `python -m engine --help` работает |
| 2 | `P02-normalize-crypto` | Нормализация ответов и шифрование на Python и JS | Тесты зелёные с обеих сторон |
| 3 | `P03-build-pipeline` | Сборщик: контент → зашифрованный `dist/` | `python -m engine check` зелёный |
| 4 | `P04-main-app` | Главный экран: этапы, вопросы, подсказки, баллы, конверты | Пройди этап 1 в браузере |
| 5 | `P05-lab-final` | Лаборатория, финал, развязка | Запроси экспертизу без основания и с основанием |
| 6 | `P06-fake-pages` | Вымышленные страницы по QR | Открой каждую с телефона |
| 7 | `P07-print-assets` | QR для печати, скриншоты переписок, аварийный конверт | Распечатай пробный лист QR, отсканируй |
| 8 | `P08-qa-deploy` | Сквозные тесты, проверка на телефоне, выкладка на домен | Полное прохождение на реальном домене |
| 9 | `P09-content-swap` | Подстановка настоящих имён и финальных текстов | Повторный прогон `check` и прохождение |

Шаг 5 опирается на главный экран из шага 4; шаг 6 можно делать сразу после шага 3. Шаг 9 — когда будут заполнены таблица персонажей и тексты документов.

## Советы по работе с Claude Code

- Для больших шагов (3, 4, 6) сначала попроси план и прочитай его, прежде чем разрешать писать код.
- Если Claude Code предлагает поменять правила игры или ответы — это решение за тобой, не соглашайся на автомате.
- После каждого шага смотри раздел «Отчёт» в его ответе: там будут `TODO(content)` — места, где не хватает текстов. Их закрою я на этапе контента.
- Не пересобирай и не перевыкладывай сайт, пока семья играет: прогресс привязан к сборке.

## Что уже решено и не обсуждается в коде

- Статический сайт без сервера; ответы проверяются в браузере по зашифрованным записям.
- Одна команда, без ведущего; прогресс в браузере главного устройства, с экспортом в файл.
- Подсказки только через сайт, со штрафом.
- Защита — от случайного подглядывания, а не от взлома (подробно в `docs/02-architecture.md`).
- Вымышленные бренды для всех «чужих» страниц.

## Что ещё не готово (контент)

- Настоящие имена и фразы родственников → `content/characters.yaml` (после таблицы персонажей).
- Тексты страниц: посты, статья, справочник, облако, вводные письма → `content/pages/`, `content/stages.yaml`.
- Тексты результатов экспертиз и развязки → `content/documents/`.
- Медиа: фото, аудио звонка, видео «репетиции» → `media/`.

До этого сборка работает на рабочих именах и заглушках — движок можно делать и тестировать уже сейчас.
