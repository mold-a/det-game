# P06. Вымышленные страницы по QR

---

Работаем по `CLAUDE.md`. Документы шага: `docs/04-pages.md` → «Вымышленные страницы», `docs/05-design.md` §2–3, `docs/02-architecture.md` §3.8–3.9, `content/pages/`, `content/world.yaml`.

**Сначала — план, без кода.** Для каждой из 7 страниц пришли в чат: характер, 4–5 цветов, шрифт, ASCII-раскладку для телефона, текстовый логотип вымышленного бренда. Сверь с `docs/05-design.md` §2: страницы не должны быть похожи ни друг на друга, ни на реальные сервисы (никаких узнаваемых логотипов, иконок, сеток и названий VK, Instagram, Telegram, Яндекса, госорганов). Жди «ок».

**Потом сделай:**

1. **Общая оболочка закрытой страницы** (`site/assets/js/pages/shell.js`): берёт ключ из `#k=…`, сохраняет его в `sessionStorage` (`detgame:page:<slug>`), убирает фрагмент из адресной строки (`history.replaceState`); при перезагрузке берёт ключ из `sessionStorage`; расшифровывает `payload.json`, медиа — в Blob URL; без ключа или с неверным — экран «Ссылка повреждена. Отсканируйте QR-код ещё раз». Для облака — форма пароля (соль и итерации — из открытой части `payload.json`); неверный пароль — «Неверный пароль», без блокировок.
2. **Семь страниц** — `call`, `gromov`, `news`, `inna`, `pharma`, `cloud`, `video` — строго по `docs/04-pages.md`: все элементы, помеченные **[Улика]**, на месте, видимы на телефоне без лишних касаний и не обрезаются.
3. **Детали по страницам:**
   - `call` — собственный аудиоплеер (play/pause, перемотка, время, громкость), работает на iOS Safari;
   - `gromov`, `inna` — даты и время постов в мире игры; декоративные кнопки неактивны и не открывают окон;
   - `news` — баннеры и боковая колонка из контента; проверка `forbidden` уже в сборщике, но страница не должна добавлять своих текстов о причине смерти;
   - `pharma` — поиск по названию и действующему веществу (нормализация `base()`), алфавитный список, карточки одного формата;
   - `cloud` — плашка публикации статичная, таблица реестра сортируется по колонкам, переписка в виде чата, папка «Для М.» с замком;
   - `video` — карточка файла, плеер, «Свойства файла».
4. **Плейсхолдеры:** если контента ещё нет (`TODO(content)`, нет фото), страница не ломается — аккуратная серая заглушка с подписью «Здесь будет …».
5. **Качество** по `docs/05-design.md` §3 для каждой страницы.
6. **Тесты** `tests/e2e/pages.spec.ts`: каждая страница открывается (закрытые — по ссылке с ключом из `salts.lock.json`), элементы [Улика] видимы на 360 px, без ключа — экран ошибки, облако — вход по паролю из контента.
7. **Самопроверка:** скриншоты каждой страницы на 360 и 1280 px; посмотри их и исправь замеченное до отчёта.

**Готово, когда:** все 7 страниц открываются с телефона по HTTPS (или в эмуляции мобильного в Playwright), тесты зелёные, ни одна страница не похожа на реальный сервис.

**Отчёт:** скриншоты, список плейсхолдеров, которые ждут контента.
