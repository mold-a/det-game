# P05. Лаборатория, финал и развязка

---

Работаем по `CLAUDE.md`. Документы шага: `docs/01-game-spec.md` §7–9, `docs/04-pages.md` → `/lab/` и `/final/`, `docs/02-architecture.md` §3.6–3.7, `docs/05-design.md`.

**Сделай:**

1. **`/lab/`:**
   - форма: объект (только объекты открытых этапов), вид, основание (только полученные документы), параметры — если у объекта они есть, с той же нормализацией и форматами, что в вопросах;
   - предупреждение о штрафе перед отправкой;
   - каждый запрос **заново** ищет запись по всем открытым этапам, при совпадении на нескольких — самый поздний этап; успех → документ в «Документах дела» и в списках типа `document`; неудача → «Недостаточно оснований для назначения экспертизы», штраф из настроек; повтор успешного и повтор отклонённого — без штрафа, но проверка всё равно выполняется (отклонённый на этапе 1 запрос может сработать на этапе 3);
   - архив запросов.
2. **Бланки документов** по `form` из front matter: `expert` (заключение эксперта), `operator` (ответ оператора), `video` (стоп-кадр с подписью), `protocol` (протокол допроса), `letter` (письмо). PT Serif, номер, дата, подпись. Печатная версия A4 без меню.
3. **`/final/`:**
   - доступ только после открытия этапа 4;
   - предупреждение о необратимости;
   - все вопросы этапа 4 (финальные и бонусный последним) — только здесь; по одному, блокировка ответа, без оценки до конца;
   - баллы финала пишутся в журнал только после последнего ответа — счёт в шапке во время финала не меняется;
   - итоги: счёт, ранг (штамп), таблица «вопрос → ответ команды → верный ответ» по всей игре; верные ответы — из поля `answers` в `data/finale.json` (путь единицы → текст верного ответа для показа): клиент не может узнать канон проваленного бонуса или финального вопроса из записей-проверок, поэтому разбор открывается только вместе с развязкой;
   - развязка из `data/finale.json`: признание → письмо → судьбы, кнопка «Дальше», в конце «Вернуться к делу».
4. **Тесты:**
   - `tests/js/lab.test.mjs` — штраф без основания, повторы без штрафа, параметры с допуском, отклонённый раньше запрос срабатывает после перехода этапа;
   - `tests/e2e/full.spec.ts` — полное прохождение до развязки, итоговый счёт равен ожидаемому (`dump-answers` кладёт в `tests/.answers.json` и баллы из настроек).

**Готово, когда:** полный путь от этапа 1 до развязки проходится руками и тестом; документы экспертиз печатаются на одном листе A4 каждый.

**Отчёт:** скриншоты лаборатории, одного документа каждого бланка, итогов и трёх экранов развязки.
