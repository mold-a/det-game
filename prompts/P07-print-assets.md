# P07. Файлы для печати: QR-коды, скриншоты переписок, аварийный конверт

---

Работаем по `CLAUDE.md`. Всё, что генерируется на этом шаге, кладётся в `print/` (в `.gitignore`, но содержит ответы — не публиковать). HTML → PDF/PNG — через Python-пакет `playwright` (`page.pdf()`, `page.screenshot()`), без вызова `npx` из Python.

**Сделай:**

1. **`python -m engine qr`:**
   - по одному QR на каждую страницу из `content/pages/`: ссылка `settings.domain + /p/<slug>/` (+ `#k=…` для закрытых); у облака — ссылка без ключа (пароль написан в записке 4-13);
   - `segno`, уровень коррекции ошибок H, PNG 1200 px и SVG;
   - `print/qr/sheet.pdf` — лист A4 с карточками для вырезания: QR 40 × 40 мм, под ним подпись из `qr_label` страницы, линии реза. Подпись — то, что видят игроки, без спойлеров;
   - самопроверка: каждый PNG декодируется обратно в ту же ссылку (библиотекой декодирования QR, если доступна; иначе — пропуск с предупреждением);
   - предупреждение, если `settings.domain` всё ещё `example.ru`.
2. **`python -m engine chatshot`** — генератор «скриншотов» телефона для бумажных материалов:
   - вход: `content/chats/<id>.yaml` (создай схему и примеры для `3-03`, `4-06`, `4-12` с `TODO(content)` в текстах):
     ```yaml
     id: "3-03"
     screens:
       - kind: notification          # экран блокировки с уведомлениями
         time: "19:41"
         date: "вторник, 10 ноября"
         items:
           - { app: "{{ w.brands.cloud }}", title: "Вход с нового устройства", text: "…", time: "19:41" }
       - kind: chat                  # переписка в вымышленном мессенджере
         owner: kirill               # чей телефон
         with: voroncov
         messages:
           - { from: kirill, time: "19:43", text: "Ваня, кто-то из театра лезет в облако. Позвони!", status: delivered }
     ```
   - рендер через Python `playwright`: HTML-шаблон вымышленного мессенджера `w.brands.messenger` (своя палитра, не Telegram и не WhatsApp), рамка телефона, строка состояния со временем и батареей; PNG 1080 × 2340 в `print/chats/`;
   - аватарки — из портретов персонажей, если есть.
3. **`python -m engine answers`** — «Аварийный конверт», `print/answers.pdf`:
   - титул: «Вскрывать, только если сайт недоступен»;
   - по этапам: вопросы и верные ответы, какой конверт открыть дальше;
   - экспертизы: какие запросы с какими основаниями дают результат, и сами тексты результатов (их нет на бумаге без сайта);
   - финал и краткая развязка;
   - HTML → PDF через Python `playwright`, A4, PT Serif.
4. **Тесты:** генерация всех трёх артефактов на текущем контенте без ошибок.

**Готово, когда:** `print/qr/sheet.pdf`, три набора PNG переписок и `print/answers.pdf` создаются одной командой каждый; пробный лист QR, напечатанный и отсканированный телефоном, открывает нужные страницы.

**Отчёт:** пути к файлам, превью (скриншоты) одной переписки и листа QR.
