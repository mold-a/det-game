# Что осталось заполнить — руководство по контенту

Движок готов. Чтобы игру можно было выпустить (`python -m engine release`), нужно заполнить заглушки `TODO(content)` и положить медиафайлы. Здесь — всё, что осталось, по исполнителям и файлам, с ограничениями, которые проверяет сборка.

Как проверить себя после любых правок:

```
python -m engine build && python -m engine check   # сборка и самопроверка — должно быть «check: OK»
python -m engine release                           # полный список того, что ещё не готово
```

Все строки в `content/` — шаблоны: имена персонажей пишутся через `{{ c.<id>.last() }}`, `{{ c.<id>.short('gen') }}` и т. п., формы, зависящие от пола, — через `{{ c.<id>.g('ушёл', 'ушла') }}`. Не вписывайте имена буквами — иначе их не заменит подстановка настоящих имён (см. `docs/03-content-format.md` §1).

Сюжетные требования к текстам — в `docs/PAPER-REQUIREMENTS.md` (бумага) и в разделах «Обязательно / Нельзя» внутри каждого файла `content/documents/*.md`.

## 2. Сценаристу (тексты)

### Вводные письма этапов — `content/stages.yaml`, поле `intro` у каждого этапа
Письма руководителя следствия майора Беляева (Markdown, до ~1500 знаков). Требования — в заглушке каждого письма.
- Этап 1: **без слов о причине смерти и болезни погибшего** (письмо почти открыто технически).
- Этапы 2–4 — по пометкам в заглушках.

### Документы, которые выдаёт сайт — `content/documents/*.md`
Заменить строку `TODO(content): полный текст документа.` полным текстом, соблюдая списки «Обязательно» и «Нельзя» в том же файле:
- `2-01.md` — заключение по ингалятору;
- `3-05.md` — анализ крови (вещества называть так же, как в справочнике);
- `3-06.md` — таблетница по дням;
- `4-08.md` — записи камер вокзала (стоп-кадр — медиа, см. ниже);
- `4-10.md` — ответ оператора связи;
- `R-01-confession.md` — протокол допроса Волкова (развязка, часть 1);
- `R-01-letter.md` — письмо отца дочери (развязка, часть 2).
