# 05. Дизайн

## 1. Система расследования: «служебный бланк и фиолетовая печать»

**Предмет.** Провинциальный следственный отдел, бумажные дела, бланки с синей разлиновкой, картонные папки «Дело №», фиолетовые штампы. Сайт — скромная служебная программа, которой этот отдел пользуется. Не «киберполиция», не нуар-плакат, не газета.

**Одна смелая деталь — печать.** Фиолетовый штамп с лёгким наклоном и неровной кромкой — единственный яркий элемент. Он отмечает решённые вопросы («Принято»), переход этапа («Конверт №2 — вскрыть») и итоговый ранг. Всё остальное — тихое и дисциплинированное.

### Цвета

| Имя | HEX | Где |
|---|---|---|
| Бланк | `#EDF0F2` | Фон страницы — холодная бумага, не кремовая |
| Разлиновка | `#C8D3DC` | Тонкие линии полей ввода и таблиц, как на бланке |
| Папка | `#D9D3C1` | Боковая панель, шапка дела — цвет картонной папки |
| Чернила | `#1F2633` | Основной текст |
| Печать | `#5B3FA3` | Штампы, основная кнопка, ссылки, фокус |
| Штраф | `#A8382B` | Только списания баллов и ошибки |

Тёмная тема — по системной настройке: фон `#1B2029`, текст `#E3E6EA`, папка `#2A2F38`, печать `#A994E6`. Контраст текста — не ниже WCAG AA.

### Шрифты

PT Sans и PT Serif — семейство ParaType, созданное как публичный шрифт для русских текстов; файлы локально в `assets/fonts/`.
- PT Sans — интерфейс: кнопки, поля, списки, шапка.
- PT Serif — тексты документов: вводные письма, результаты экспертиз, развязка (межстрочный 1,6).
- Шкала: 14 / 16 / 19 / 23 / 28 px. База 16 px, на телефоне не меньше 16 px в полях ввода (иначе iOS увеличивает страницу).
- Без капслока в подписях, без разрядки. Номера документов (`2-01`) — тем же PT Sans с табличными цифрами.

### Раскладка главного экрана

```
┌──────────────────────────────────────────────────────────────┐
│ Дело № 47/2026      Команда «…»              Счёт 85   ①②③④  │  ← шапка цвета папки
├───────────────────────────────────────┬──────────────────────┤
│ Этап 2                                │ Документы дела       │
│ ┌ Письмо руководителя (свернуть) ───┐ │  1-01 Вводное письмо │
│ │ PT Serif, до 70 знаков в строке    │ │  1-03 Карта вызова   │
│ └────────────────────────────────────┘ │  2-01 Экспертиза ⚗   │
│                                       │                      │
│ Перемещения охранника                 │ [ Лаборатория ]      │
│  ушёл ____  вернулся ____             │                      │
│  [Проверить]  Подсказка (−10)         │ Журнал баллов ▸      │
│                       ╭ ПРИНЯТО ╮     │                      │
│ …                     ╰─────────╯     │                      │
└───────────────────────────────────────┴──────────────────────┘
```

- Выравнивание по левому краю везде. Ширина колонки вопросов — до 720 px.
- Вопросы — не одинаковые «карточки с тенью»: каждый вопрос — участок бланка, отделённый линией разлиновки; решённый получает штамп, а не зелёную рамку.
- Телефон: одна колонка, документы и лаборатория — под вопросами, шапка компактная, счёт виден всегда.

### Движение

Одно: штамп «Принято» опускается на вопрос (масштаб 1,15 → 1, лёгкий поворот, 180 мс). При `prefers-reduced-motion` — появляется без анимации. Других анимаций при загрузке нет.

### Тексты интерфейса

Короткие, служебные, без восклицаний и извинений. Кнопка называет действие: «Проверить», «Направить запрос», «Открыть подсказку (−20)». Ошибка говорит, что не так и что делать: «Время в формате ЧЧ:ММ, например 08:15».

## 2. Вымышленные страницы

У каждой — собственная узнаваемая идентичность, не похожая на систему расследования и друг на друга. Бренды — вымышленные, из `world.yaml`; логотип — текстовый знак, нарисованный CSS/SVG.

| Страница | Характер | Палитра (основа) | Шрифт |
|---|---|---|---|
| `call` — дежурная часть | Тёмная служебная консоль, таблица вызовов | `#16202B`, `#2E4052`, акцент `#E0B341` | PT Sans |
| `gromov` — соцсеть | Чистая лента, круглые аватары, официоз постов контрастирует с лайками | `#FFFFFF`, `#F1F4F7`, бренд `#2F7D7A` | Системный sans-serif |
| `news` — портал | Перегруженный региональный портал: баннеры местных фирм (вымышленных, с юмором), красная плашка «Срочно» | `#FFFFFF`, `#F5F5F5`, бренд `#C8262C` | PT Serif для заголовков, sans для текста |
| `inna` — фотосеть | Квадратная сетка фото, минимум интерфейса | `#FFFFFF`, `#111827`, бренд `#E8A33D` | Системный sans-serif |
| `pharma` — справочник | Клинично и сухо, много воздуха, таблицы | `#FFFFFF`, `#EEF5F2`, бренд `#2D7A5F` | PT Sans |
| `cloud` — облако | Дружелюбный файловый менеджер, жёлтая плашка публикации | `#F7FAFC`, `#E3EEF7`, бренд `#3A7BD5`, предупреждение `#F2C94C` | Системный sans-serif |
| `video` — изъятые файлы | Тот же стиль, что система расследования | см. §1 | PT Sans |

Правила:
- Не копировать вёрстку, иконки, цвета и названия реальных сервисов. Ориентир — «узнаётся жанр», а не «узнаётся бренд».
- Декоративные кнопки (лайк, подписаться, поделиться) выглядят настоящими, но ничего не делают и не открывают окон.
- Фото с родственниками — главное содержимое; интерфейс вокруг не спорит с ними.

## 3. Качество для всех страниц

- Работает на ширине 360 px без горизонтальной прокрутки; проверять 360, 768, 1280.
- Видимый фокус с клавиатуры (обводка цветом печати), порядок табуляции логичный.
- Цели нажатия не меньше 44 × 44 px.
- `prefers-reduced-motion` и `prefers-color-scheme` соблюдаются.
- Печатная версия документов лаборатории и развязки: A4, без меню, чёрным по белому.
- Картинки — с `alt`, в WebP/JPEG, не больше 300 КБ на фото в ленте.
