# 06. Тестирование и самопроверка

## 1. Кросс-языковые векторы — `tests/vectors/`

| Файл | Что | Кто генерирует | Кто проверяет |
|---|---|---|---|
| `normalize.json` | Вход, тип, ожидаемый выход (или `null`) — не меньше 60 случаев | Пишутся руками | `pytest` и `npm run test:js` |
| `crypto.json` | PBKDF2, HKDF и AES-GCM: входы и ожидаемые байты; контейнеры, зашифрованные Python | `python -m engine vectors` | `npm run test:js` расшифровывает и сверяет |

Правило: любое изменение `normalize` или `crypto` → обновить векторы → обе стороны зелёные.

## 2. Python (`pytest`)

- Нормализация по векторам, плюс граничные случаи времени и дат.
- Криптография: шифрование ↔ расшифровка, неверный ключ и неверный AAD → ошибка.
- Валидация контента: на испорченных копиях `content/` (нет подсказки, неверный ID ответа, дубликат ID, опечатка в шаблоне) сборка падает с понятным сообщением.
- Склонение: таблица форм для всех персонажей строится без исключений.
- `salts.lock.json`: повторная сборка не меняет соли и ключи страниц; новая единица дописывает соль.

## 3. Самопроверка сборки — `python -m engine check`

Обязательна после каждой сборки, падает при любой ошибке.

1. **Прохождение.** Для каждого этапа: правильные канонические ответы → ключ следующего этапа → пакет расшифровывается.
2. **Все варианты.** Каждый допустимый вариант каждой единицы проверяется как верный и даёт тот же канон.
3. **Неверные ответы.** Для каждой единицы 5 правдоподобных неверных ответов (соседние варианты списка, время ±(допуск+1) мин, пустая строка) — не проходят.
4. **Экспертизы.** Каждая запись открывается каждым допустимым основанием и не открывается чужим основанием или до своего этапа.
5. **Страницы.** Каждая закрытая страница расшифровывается своим ключом; облако — паролем из контента.
6. **Развязка.** Расшифровывается ключом этапа 4.
7. **Leak scan.** Во всех текстовых файлах `dist/` (html, js, css, json, svg, txt, xml) не встречаются:
   - канонические ответы и варианты единиц типов `text`, `time`, `date`, `number` (кроме `leak_scan: false`);
   - первые 40 символов каждой подсказки, вводного письма этапов 2–4, результата экспертизы, развязки и текстов закрытых страниц;
   - строки из `settings.leak_watchlist`.
   - значения `params_answer` экспертиз длиной от 4 символов;
   - нейтральные примеры из интерфейса не должны совпадать с ответами (проверяется отдельно).
   Поиск — по целым словам (границы токенов), в сыром виде и после `base()`; JSON-экранирование `\uXXXX` раскрывается перед поиском; поля `n` и `c` зашифрованных контейнеров и файлы `*.bin` пропускаются — base64url даёт ложные совпадения.
   Плюс: ни один медиафайл, на который ссылается только зашифрованный контент, не лежит в `dist/` открытым.
8. **Заглушки.** Список `TODO(content)`; с `--release` — ошибка.
9. **Отчёт.** Таблица: этапов, единиц, вариантов, экспертиз, страниц, размер `dist/`, самый большой файл.

## 4. JS (`npm run test:js`)

- Нормализация по `normalize.json`.
- Расшифровка контейнеров из `crypto.json`.
- Модуль состояния: начисления и списания, повторный неверный ответ без штрафа, автоподсказка после N ошибок, экспорт → импорт → то же состояние.
- Работа без `localStorage` (имитация исключения) — игра идёт в памяти.

## 5. Сквозные тесты (Playwright, `tests/e2e/`)

Против `python -m engine serve`. Ответы тесты берут из `tests/.answers.json` (`python -m engine dump-answers`): в `content/` ответы — шаблоны Jinja2, Node их не отрендерит.
- **Полное прохождение** правильными ответами: этап 1 → 4 → финал → развязка; итоговый счёт совпадает с ожидаемым.
- **Ошибки и подсказки:** 3 неверные попытки → автоподсказка, покупка уровней 2 и 3, счёт в журнале верный.
- **Лаборатория:** запрос без основания −5; повтор без штрафа; запрос с основанием → документ появился в списке и в выборе типа `document`.
- **Перезагрузка** посреди этапа 3 → прогресс на месте.
- **Финал:** после ответа вернуться нельзя; развязка показывается.
- **Закрытые страницы:** с ключом — открываются, без ключа и с испорченным — «Ссылка повреждена».
- **Вёрстка:** скриншоты всех страниц на 360, 768, 1280 px, проверка отсутствия горизонтальной прокрутки.
- **Производительность:** время одной проверки ответа и вывода ключа этапа при CPU throttling ×4 — в отчёт.

- [ ] Поиск «пропранолол противопоказания» в обычном поисковике выдаёт астму на первой странице (запасной вариант — справочник `pharma`).
- [ ] Видео и аудио воспроизводятся на iPhone и Android.
- [ ] Полное прохождение человеком, который не знает сюжета, или хотя бы автором с таблицей ответов.
- [ ] Аварийный конверт распечатан и запечатан.
