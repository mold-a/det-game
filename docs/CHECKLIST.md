## 1. Контент

- [ ] Нет заглушек: `python -m engine build --release` проходит. Список того, что осталось, печатает `python -m engine build`.
  - Учитываются и `TODO(content)` в комментариях YAML, и переписки `content/chats/*.yaml`.
- [ ] Настоящие имена подставлены (`python -m engine import-cast <xlsx>`, P09), формы вычитаны: `python -m engine names`. Неверные падежи исправлены в `characters.yaml → forms`.

- [ ] `content/settings.yaml → domain` — свой домен с `https://`, без пути. Не `example.ru`.
- [ ] Пароль облака (`content/pages/cloud/page.yaml → password`) задан, не словарное слово; тот же напечатан в записке 4-13.
- [ ] Тексты страниц есть: `content/pages/news/article.md`, `content/pages/cloud/if_you_read_this.md`.
- [ ] Новые документы 3-10 (объяснение Громовой) и 3-11 (повторный опрос Вольской) — в бумажной папке конверта 3. Бонусы s3.b3 и s4.fb2 на них опираются.

## 3. Сборка и проверка

- [ ] `python -m pytest` и `npm run test:js` зелёные; сквозные тесты — `npx playwright test` после `build`.
- [ ] `python -m engine release` прошёл: таблица `check` вся `OK`, архив `print/dist-<buildId>.zip` создан.
- [ ] `engine/salts.lock.json` закоммичен. **Не запускать `rotate-salts`** после печати QR: он меняет ключи закрытых страниц, старые QR перестают работать. Если всё же запустили — перепечатать QR (`python -m engine qr`).
- [ ] Окружение без интернет-доступа к Playwright: для печати задана `PW_CHROMIUM_PATH` (docs/DEV.md).

## 5. Выкладка (docs/DEPLOY.md)

- [ ] Сайт открыт по HTTPS на своём домене, без предупреждений браузера; `http://` переадресует на `https://`.
- [ ] `robots.txt` (`Disallow: /`) и `noindex` на месте; заголовки кеширования проверены `curl -sI` (DEPLOY §4).
- [ ] Выложено только содержимое `dist/` (или распакованный архив релиза), не репозиторий.

## 6. Проверка на телефонах (по мобильному интернету, Wi-Fi выключен)

- [ ] Каждый напечатанный QR-код отсканирован телефоном и открывает нужную страницу; закрытые страницы расшифровываются.
- [ ] Пароль облака из записки работает, в том числе с другим регистром и пробелами.
- [ ] Проверка ответа на телефоне занимает меньше секунды.
- [ ] Видео и аудио воспроизводятся на iPhone и Android.
- [ ] Поиск «пропранолол противопоказания» в обычном поисковике выдаёт астму на первой странице. Запасной вариант — справочник `pharma` по QR.
- [ ] Сайт открывается у 2–3 разных операторов. Хостинги вне России — особенно внимательно (DEPLOY §2).
