# Требования к бумажным документам

Тексты бумажных документов (конверты 1–4) лежат в `content/paper/<id>.md` и печатаются командой `python -m engine paper` (см. `docs/03-content-format.md`, раздел «8а»). Здесь — факты, которые **обязательно** должны в них быть, чтобы сюжет сходился с вопросами, ответами и развязкой. Источник каждого требования — запись в `docs/STORY-ISSUES.md`.
