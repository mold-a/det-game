## 2. `content/pages/gromov/page.yaml`

1. Пост `2026-11-08T11:15` («Поздравляю коллектив областного драматического театра с предстоящей премьерой…») — карточка-ссылка под постом:
   ```yaml
   link: { page: theater, text: "Афиша театра" }
   ```
2. Пост `2026-11-11T12:40` («Скоропостижно ушёл из жизни народный артист…»):
   ```yaml
   link: { page: krug-voroncov, text: "{{ c.voroncov.first() }} {{ c.voroncov.last() }}" }
   ```
3. Собственные комментарии Громовой (`author: "{{ c.gromov.short() }}"`) — `page: gromov`. Остальные комментаторы без `page` → `krug-private`.
4. При переводе на `type: social` отображаемое имя в её комментариях лучше сделать как у остальных профилей: `"{{ c.gromov.first() }} {{ c.gromov.last() }}"` вместо `short()` («Фамилия И. О.» в соцсети выглядит как протокол).

Легенда не трогается: пост 10.11 19:30 и геометка — без изменений; новые ссылки её не опровергают.

## 3. `content/pages/news/`

1. `article.md`, первый абзац: название театра — ссылкой на сайт театра:
   ```markdown
   Вечером 10 ноября на сцене [{{ w.theater.full }}]({{ link('theater') }}) состоялась долгожданная премьера…
   ```
2. `article.md`, перед строкой «*Материал обновляется.*» — новый абзац:
   ```markdown
   Слова памяти можно оставить на [странице артиста в соцсети «{{ w.brands.social }}»]({{ link('krug-voroncov') }}).
   ```
3. `page.yaml`, `sidebar` — добавить `page:` трём пунктам (заголовки и время не менять, они совпадают с новыми статьями):
   ```yaml
   - { datetime: "2026-11-09T21:35", title: "Хоккейные «Верхнеречинские медведи» дома уступили 2:3. …", page: news-hockey }
   - { datetime: "2026-11-10T16:20", title: "На улице Садовой заделали яму, … Через сутки рядом появилась новая", page: news-yama }
   - { datetime: "2026-11-09T18:45", title: "Центральная библиотека объявила неделю возврата книг без штрафов. …", page: news-library }
   ```
   Остальные пункты (отопление, снег, огурцы) — без `page`, как заголовки без статьи.
4. `forbidden` у `news-*` можно скопировать из `news` (`["астма", "таблетк", "отравлен", "21:18"]`): в новых статьях этого нет, но проверка не помешает.

## 4. `content/pages/cloud/` → `auction`

Ссылка на сайт клуба должна быть только в облаке (этап 4). Два варианта, выбирает режиссёр:

**А (без изменения схемы, рекомендую).** `if_you_read_this.md`, раздел «**Реестр.**» — после фразы «Там же лежит моя переписка с {{ c.zavyalov.last('ins') }}.» добавить:
```markdown
Для сравнения: у «вечеров» есть и витрина — [сайт клуба]({{ link('auction') }}), «только по приглашению». Там всё выглядит прилично. Сверьте с моей таблицей.
```
Голос Воронцова в письме — сдержанный, без смайлов (письмо официальное), так что фраза в тон.

**Б (новое поле схемы `CloudFolder.link`).** У папки `registry`:
```yaml
link: { page: auction, text: "Сайт клуба «{{ w.money.auctions }}»: архив лотов" }
```
Требует правки `CloudFolder` у frontend-dev.
