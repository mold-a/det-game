# 04. Страницы

Две группы страниц:
- **Система расследования** (`/`, `/lab/`, `/final/`) — инструмент команды на главном устройстве.
- **Вымышленные страницы** (`/p/<slug>/`) — «улики из интернета», открываются по QR на любом телефоне и не влияют на счёт.

Все тексты, имена, даты и посты — из `content/pages/<slug>/`. Ниже — структура и обязательные элементы. **[Улика]** — элемент, на котором держится цепочка рассуждений: его нельзя прятать, обрезать или менять при вёрстке.

---

## Система расследования

Вымышленная служебная система «Электронное дело» следственного отдела по вымышленному городу из `world.yaml`. Без гербов и символики реальных ведомств.

### `/` — главный экран

**Первый запуск:**
- Название игры, 5–6 строк правил (как устроены этапы, конверты, подсказки и штрафы, что прогресс хранится в этом браузере).
- Поле «Название команды», кнопка «Открыть дело».
- Сообщение: «Вскройте конверт №1 — папку дела».

**Во время игры** (ноутбук — две колонки, телефон — одна):
- Шапка: номер дела, название команды, счёт, индикатор этапов 1–4.
- Текущий этап:
  - вводное письмо (сворачивается, при первом входе развёрнуто);
  - карточки вопросов: обязательные сверху, бонусные ниже с пометкой «Бонус, одна попытка»;
  - у каждой карточки: статус (не решён / решён / закрыт), поле ввода по типу, кнопка «Проверить», кнопка «Подсказка (−N)», число неверных попыток.
- Боковая панель:
  - «Документы дела» — список полученных документов (ID, название, отметка «бумага», «онлайн» или «экспертиза»); онлайн-документы и результаты экспертиз открываются по клику;
  - кнопка «Лаборатория»;
  - «Журнал баллов» (сворачиваемый).
- Пройденные этапы — свёрнуты, с канонами ответов команды.
- Меню: правила, сохранить прогресс в файл, загрузить из файла, начать заново.

**Переход этапа:** модальное окно «Ответ принят. Откройте конверт №N», кнопка «Конверт вскрыт» → вводное письмо нового этапа. Во время вывода ключа — индикатор «Проверяем…» (PBKDF2 занимает до секунды).

**Ввод по типам:**
- `time` — поле `ЧЧ:ММ`, на телефоне числовая клавиатура.
- `order` — перетаскивание карточек (мышью и пальцем) плюс кнопки ↑/↓ для доступности.
- `person`/`persons` — сетка карточек с портретом и ФИО, если фото есть; иначе список.
- `document` — выпадающий список полученных документов.
- `form` — поля подряд, одна кнопка «Проверить» на всю форму.

### `/lab/` — лаборатория

- Форма: «Объект», «Вид исследования», «Основание» (только полученные документы), параметры (появляются, если у объекта они есть), кнопка «Направить запрос».
- Перед отправкой — предупреждение: «Запрос без оснований: −N баллов» (N из `penalties.lab_no_basis`).
- Архив запросов: выполненные (с открытием документа) и отклонённые.
- Результат — в стиле официального документа: бланк, номер, дата, подпись эксперта, кнопка «Печать» (печатная CSS-версия на A4).

### `/final/` — финал и развязка

- Доступен только после открытия этапа 4, иначе — «Финал откроется после этапа 3».
- Предупреждение о необратимости → вопросы по одному → после каждого «Ответ зафиксирован» без оценки.
- Итоги: счёт, ранг, таблица «вопрос → ваш ответ → верный ответ» по всей игре.
- Развязка: признание → письмо → судьбы персонажей; кнопка «Дальше», в конце — «Вернуться к делу».

## Вымышленные страницы

Общие требования:
- Правдоподобно, но не копия реального сервиса: свой логотип-текст, своя палитра, своя сетка. Бренды — из `world.yaml`.
- Мобильная вёрстка в первую очередь (их открывают с телефона по QR).
- Никаких внешних запросов, кнопки «Поделиться», «Войти», «Подписаться» — неактивные декорации, без всплывающих окон.
- Время и даты — в мире игры (ноябрь 2026), не реальные «сейчас».
- Закрытые страницы (`locked: true`): без ключа — экран «Ссылка повреждена. Отсканируйте QR-код ещё раз».

| Slug | Документ | Доступ | Бренд из `world.yaml` |
|---|---|---|---|
| `call` | 1-05 | Открыта | Дежурная часть отдела полиции |
| `gromov` | 1-12 | Открыта | Соцсеть `brands.social` |
| `news` | 1-13 | Открыта | Портал `brands.news` |
| `inna` | 2-09 | Ключ в QR (конверт 2) | Фотосеть `brands.photo` |
| `pharma` | 3-09 | Ключ в QR (конверт 3) | Справочник `brands.pharma` |
| `cloud` | 4-01 | Пароль из записки (конверт 4) | Облако `brands.cloud` |
| `video` | 4-07 | Ключ в QR (конверт 4) | Система «Электронное дело», раздел «Изъятые файлы» |

### `call` — запись анонимного звонка

- Карточка вызова: дата и время **[Улика: 11.11.2026, 07:50:12]**, «Номер скрыт», длительность, оператор.
- Аудиоплеер (свой, не стандартный `<audio controls>`): воспроизведение, перемотка, время, громкость; статичная «волна».
- Строка: «Расшифровка — в материалах дела (1-05)». Расшифровки на странице нет: речевую привычку игроки должны **услышать** или прочитать на бумаге.

### `gromov` — профиль в соцсети

- Шапка профиля: обложка, аватар, ФИО, должность, город.
- Лента 8–10 постов за месяц: официальные мероприятия, поздравления, фото. Тон — канцелярский.
- **[Улика]** Пост от 10.11.2026, **19:30**, геометка **Северогорск**: «Рабочее совещание по развитию культурной инфраструктуры», фото за столом.
- У постов — дата, время, отметки «нравится», 1–3 комментария (можно с семейным юмором).

### `news` — новостной портал

- Статья от 11.11.2026: «На премьере скончался народный артист Иван Воронцов» (имя — из `characters`). Фото в роли Арбенина.
- Официальная версия — сердечный приступ; цитата худрука о «невосполнимой утрате».
- Боковая колонка — 5–6 посторонних новостей города (атмосфера, юмор).
- Комментарии читателей — 4–6 штук (атмосфера; без улик).
- **Нельзя:** слова «астма», «таблетки», «отравление».

### `inna` — профиль в фотосети

- Сетка 9–12 фото, по клику — фото крупно, подпись, дата, отметки.
- **[Улика]** Фото от 11.11.2026 в броши из костюмерки, подпись в духе «новая красота». Брошь на фото должна совпадать с описью 2-08.
- Остальные фото — быт, еда, кошки, кофе (атмосфера).

### `pharma` — справочник лекарств

- Поиск по названию (торговому и действующему веществу, без учёта регистра и «ё»), алфавитный список.
- Карточка препарата: торговые названия, действующее вещество, фармакологическая группа, показания, **противопоказания**, побочные эффекты.
- 8–10 препаратов, все в одном формате; нужный ничем не выделен.
- **[Улика]** Пропранолол (торговое название Анаприлин): в противопоказаниях — бронхиальная астма; в побочных — бронхоспазм.
- Вымышленный «Седарин» оформлен так же, как настоящие.
- Внизу мелко: «Справочник создан для игры. Не используйте для лечения».

### `cloud` — облако погибшего

- Экран входа: логин (уже заполнен, неизменяем), поле пароля, кнопка «Войти». Неверный пароль — «Неверный пароль» без штрафа.
- После входа — жёлтая плашка: «Публикация по расписанию: **13.11.2026, 10:04**. Последнее подтверждение: 10.11.2026, 10:04». Таймер не тикает в реальном времени — показывается статично.
- Папки:
  - «Реестр» — таблица сделок «Закрытых вечеров» за 10 лет (дата, лот, покупатель, цена, комментарий), сортировка по колонкам. **[Улика]** Строка о табакерке Вольской с пометкой «З. знал, что копия».
  - «Переписка» — переписка Воронцова с Завьяловым в виде чата (ультиматум).
  - «Если вы это читаете» — обращение к тому, кто откроет архив.
  - «Для М.» — замок: «Папка защищена отдельным паролем». Содержимое — только в развязке.

### `video` — видео «репетиции»

- Карточка файла в стиле «Электронного дела»: «Изъято с телефона Волкова А. А.» (имя — из `characters`).
- Имя файла **[Улика: VID_20261108_141203.mp4]**, размер.
- Видеоплеер.
- Кнопка «Свойства файла»: дата создания **[Улика: 08.11.2026 14:12:03]**, модель устройства, длительность, разрешение.
- В видео за окном дневной свет — это часть съёмки, страница ничего не подсвечивает.
