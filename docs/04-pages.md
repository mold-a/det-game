# 04. Страницы

Две группы страниц:
- **Система расследования** (`/`, `/lab/`, `/final/`) — инструмент команды на главном устройстве.
- **Вымышленные страницы** (`/p/<slug>/`) — «улики из интернета», открываются по QR на любом телефоне и не влияют на счёт.

Все тексты, имена, даты и посты — из `content/pages/<slug>/`. Ниже — структура и обязательные элементы. **[Улика]** — элемент, на котором держится цепочка рассуждений: его нельзя прятать, обрезать или менять при вёрстке.

---

## Система расследования

Вымышленная служебная система «Электронное дело» следственного отдела по вымышленному городу из `world.yaml`. Без гербов и символики реальных ведомств.

### `/` — главный экран

**Первый запуск:**
- Название игры, 5–6 строк правил (как устроены этапы, конверты, подсказки и штрафы, что прогресс хранится в этом браузере).
- Поле «Название команды», кнопка «Открыть дело».
- Сообщение: «Вскройте конверт №1 — папку дела».

**Во время игры** (ноутбук — две колонки, телефон — одна):
- Шапка: номер дела, название команды, счёт, индикатор этапов 1–4.
- Текущий этап:
  - вводное письмо (сворачивается, при первом входе развёрнуто);
  - карточки вопросов: обязательные сверху, бонусные ниже с пометкой «Бонус, одна попытка»;
  - у каждой карточки: статус (не решён / решён / закрыт), поле ввода по типу, кнопка «Проверить», кнопка «Подсказка (−N)», число неверных попыток.
- Боковая панель:
  - «Документы дела» — список полученных документов (ID, название, отметка «бумага», «онлайн» или «экспертиза»); онлайн-документы и результаты экспертиз открываются по клику;
  - кнопка «Лаборатория»;
  - «Журнал баллов» (сворачиваемый).
- Пройденные этапы — свёрнуты, с канонами ответов команды.
- Меню: правила, сохранить прогресс в файл, загрузить из файла, начать заново.

**Переход этапа:** модальное окно «Ответ принят. Откройте конверт №N», кнопка «Конверт вскрыт» → вводное письмо нового этапа. Во время вывода ключа — индикатор «Проверяем…» (PBKDF2 занимает до секунды).

**Ввод по типам:**
- `time` — поле `ЧЧ:ММ`, на телефоне числовая клавиатура.
- `order` — перетаскивание карточек (мышью и пальцем) плюс кнопки ↑/↓ для доступности.
- `person`/`persons` — сетка карточек с портретом и ФИО, если фото есть; иначе список.
- `document` — выпадающий список полученных документов.
- `form` — поля подряд, одна кнопка «Проверить» на всю форму.

### `/lab/` — лаборатория

- Форма: «Объект», «Вид исследования», «Основание» (только полученные документы), параметры (появляются, если у объекта они есть), кнопка «Направить запрос».
- Перед отправкой — предупреждение: «Запрос без оснований: −N баллов» (N из `penalties.lab_no_basis`).
- Архив запросов: выполненные (с открытием документа) и отклонённые.
- Результат — в стиле официального документа: бланк, номер, дата, подпись эксперта, кнопка «Печать» (печатная CSS-версия на A4).

### `/final/` — финал и развязка

- Доступен только после открытия этапа 4, иначе — «Финал откроется после этапа 3».
- Предупреждение о необратимости → вопросы по одному → после каждого «Ответ зафиксирован» без оценки.
- Итоги: счёт, ранг, таблица «вопрос → ваш ответ → верный ответ» по всей игре.
- Развязка: признание → письмо → судьбы персонажей; кнопка «Дальше», в конце — «Вернуться к делу».

## Вымышленные страницы

Общие требования:
- Правдоподобно, но не копия реального сервиса: свой логотип-текст, своя палитра, своя сетка. Бренды — из `world.yaml`. Каждый сервис узнаваем по жанру, но со своим стилем.
- Мобильная вёрстка в первую очередь (их открывают с телефона по QR или по ссылке с другой страницы), 360 px без горизонтальной прокрутки, тёмная тема по системной настройке, `prefers-reduced-motion`. Шрифты — только локальные PT Sans и PT Serif.
- Никаких внешних запросов.
- **Каждый видимый элемент что-то делает** (решение 21.10.2026, отменяет прежнее «кнопки — неактивные декорации»):
  - ссылки ведут на страницы; логотип — на главную сервиса, где она есть (у «Круга» — `krug`), иначе — наверх;
  - вкладки и разделы переключаются (с клавиатуры — стрелки, Home, End), фото открываются крупно (кнопка «Закрыть», Esc);
  - действия аккаунта («Подписаться», «Написать», «Нравится», «Поделиться», «Войти», «Отметить», «Написать комментарий…») показывают окно сервиса в стиле бренда: «Чтобы подписаться, войдите в «Круг»» и кнопка «Понятно». Форм входа нет, чтобы игроки не искали пароль;
  - пункты подвала «О сервисе», «Правила», «Помощь» открывают короткие тексты из `content/pages/_brands.yaml` (docs/03 §8);
  - авторы комментариев и друзья без своей страницы ведут на заглушку «Пользователь ограничил доступ к своей странице» (`krug-private`).
- Доступность: окна — нативный `<dialog>` (фокус внутри окна, Esc закрывает, фокус возвращается на кнопку); вкладки — `role="tablist"/"tab"/"tabpanel"`; цели нажатия ≥ 44 px; фокус виден.
- Время и даты — в мире игры (ноябрь 2026), не реальные «сейчас».
- Закрытые страницы (`locked: true`): без ключа — экран «Ссылка повреждена. Отсканируйте QR-код ещё раз».
- Игроки находят страницы сами: по QR-коду или напечатанному адресу из бумажных документов (только у страниц с документом `doc`) и по ссылкам на других страницах. Списка всех страниц на сайте нет.

### Ссылки между страницами

- В структурных полях — `page: <slug>`; в Markdown-текстах и строках контента — `{{ link('slug') }}`, например `[Афиша театра]({{ link('theater') }})`.
- `link()` возвращает адрес: для открытой страницы — `/p/<slug>/`, для закрытой по ключу — `/p/<slug>/#k=<ключ>` (ровно тот же адрес, что зашит в QR-код, без домена), для облака — `/p/cloud/` (пароль — в записке).
- Сборка проверяет каждую ссылку со страницы A на страницу B (ошибка — сборка и `check` падают):
  - B существует;
  - этап B не позже этапа A (`stage` страницы — этап документа `doc` или поле `stage`);
  - из открытой страницы можно ссылаться только на страницы этапа 1 (иначе ключ закрытой страницы окажется в открытом файле).
- Предупреждение: страница без `doc`, на которую никто не ссылается (QR нет, достичь нельзя).
- `check` повторно проверяет готовый HTML: цель есть, ключ в адресе совпадает с ключом QR, правила этапов.

### Типы страниц

`type` в `page.yaml` по умолчанию равен `slug` (`call`, `inna`, `news`, `pharma`, `cloud`, `video`). Шаблон — `site/templates/pages/<type>.html`, стили — `site/assets/css/pages/<type>.css`, интерактив — `site/assets/js/pages/page-ui.js` (общий) и модуль типа.

| `type` | Что это |
|---|---|
| `social` | профиль в «Круге» (`gromov`, `krug-*`) |
| `social_home` | главная «Круга»: поиск людей по открытым профилям этапа 1, «Популярное в городе» |
| `social_stub` | закрытый профиль: «Пользователь ограничил доступ к своей странице» |
| `site` | сайт организации из разделов и блоков; скин `theater` (бархат, афиша), `fund` (строгий фонд), `auction` (тёмный клуб «по приглашению», золото) |
| `news` | статья портала; дополнительные статьи — slug `news-*` с той же схемой; пункт боковой колонки с `page:` — ссылка |

| Slug | Документ | Доступ | Бренд из `world.yaml` |
|---|---|---|---|
| `call` | 1-05 | Открыта | Дежурная часть отдела полиции |
| `gromov` | 1-12 | Открыта | Соцсеть `brands.social` (`type: social`) |
| `news` | 1-13 | Открыта | Портал `brands.news` |
| `krug` | — (`stage: 1`) | Открыта, по ссылкам | Главная соцсети `brands.social` |
| `krug-private` | — (`stage: 1`) | Открыта, по ссылкам | Заглушка закрытого профиля |
| `inna` | 2-09 | Ключ в QR (конверт 2) | Фотосеть `brands.photo` |
| `pharma` | 3-09 | Ключ в QR (конверт 3) | Справочник `brands.pharma` |
| `cloud` | 4-01 | Пароль из записки (конверт 4) | Облако `brands.cloud` |
| `video` | 4-07 | Ключ в QR (конверт 4) | Система «Электронное дело», раздел «Изъятые файлы» |

Остальные страницы сети (театр, фонд, профили «Круга», `news-*`, клуб «Закрытые вечера») — по `docs/REDESIGN-2026-10.md` §4.3; их содержимое пишет сценарист.

### `social` — профиль в «Круге»

- Шапка: логотип «круг» (→ главная), «Поиск людей» (→ главная, поиск), «Войти» (окно).
- Профиль: обложка, аватар (крупно по нажатию), имя, должность, город, «Подписаться» и «Написать» (окна), число публикаций и друзей.
- Вкладки «Публикации», «Фото», «Сведения» (имя, должность, город, «О себе», друзья).
- Пост: дата, время, геометка, текст (Markdown в одну строку), фото (крупно), необязательная карточка-ссылка `link`, «Нравится» (окно), «Комментарии» (свернуть/развернуть), «Поделиться» (окно), «Написать комментарий…» (окно). Автор комментария — ссылка на `page` или на `krug-private`.
- Подвал: «О сервисе», «Правила», «Помощь».

### `gromov` — профиль в соцсети

- Страница типа `social`, документ 1-12. Лента 8–10 постов за месяц: официальные мероприятия, поздравления, фото. Тон — канцелярский.
- **[Улика]** Пост от 10.11.2026, **19:30**, геометка **Северогорск**: «Рабочее совещание по развитию культурной инфраструктуры», фото за столом.
- У постов — дата, время, отметки «нравится», 1–3 комментария (можно с семейным юмором). Собственные ответы Громовой в комментариях ведут на её страницу.

### `social_home` и `social_stub`

- Главная: заставка, поиск людей (по имени, без учёта регистра и «ё»; находит только открытые профили `social` этапа 1), «Популярное в городе» (ссылки на страницы).
- Заглушка: замок, фраза из `text`, «Добавить в друзья» (окно), «На главную».

### `site` — сайт организации

- Шапка: логотип (→ первый раздел), девиз `tagline`, меню разделов; у скина `auction` — «Войти» (окно «вход по приглашению»).
- Разделы — вкладки с адресами `#<id>` (работает кнопка «Назад»); блоки раздела: `text` (Markdown), `cards` (карточки: фото крупно, ссылка `page`), `table` (на телефоне строки складываются в карточки), `notice` (плашка: траур, «вход по приглашению»).
- Подвал: те же разделы и строка `footer`.

### `call` — запись анонимного звонка

- Карточка вызова: дата и время **[Улика: 11.11.2026, 07:50:12]**, «Номер скрыт», длительность, оператор.
- Аудиоплеер (свой, не стандартный `<audio controls>`): воспроизведение, перемотка, время, громкость; статичная «волна».
- Строка: «Расшифровка — в материалах дела (1-05)». Расшифровки на странице нет: речевую привычку игроки должны **услышать** или прочитать на бумаге.

### `gromov` — профиль в соцсети

- Шапка профиля: обложка, аватар, ФИО, должность, город.
- Лента 8–10 постов за месяц: официальные мероприятия, поздравления, фото. Тон — канцелярский.
- **[Улика]** Пост от 10.11.2026, **19:30**, геометка **Северогорск**: «Рабочее совещание по развитию культурной инфраструктуры», фото за столом.
- У постов — дата, время, отметки «нравится», 1–3 комментария (можно с семейным юмором).

### `news` — новостной портал

- Статья от 11.11.2026: «На премьере скончался народный артист Иван Воронцов» (имя — из `characters`). Фото в роли Арбенина.
- Официальная версия — сердечный приступ; цитата худрука о «невосполнимой утрате».
- Боковая колонка — 5–6 посторонних новостей города (атмосфера, юмор).
- Комментарии читателей — 4–6 штук (атмосфера; без улик). Имя автора открывает окно портала: профили читателей скрыты.
- Рубрики: «Главное» — на главную портала, остальные открывают окно портала; баннеры — окно «рекламное объявление»; «Печать» печатает статью.
- Пункты боковой колонки со `page:` — ссылки на статьи `news-*`; остальные — окно «Полный текст недоступен».
- **Нельзя:** слова «астма», «таблетки», «отравление».

### `inna` — профиль в фотосети

- Сетка 9–12 фото, по клику — фото крупно, подпись, дата, отметки. «Войти», «Подписаться», «Отметить» — окна сервиса; аватар открывается крупно.
- **[Улика]** Фото от 11.11.2026 в броши из костюмерки, подпись в духе «новая красота». Брошь на фото должна совпадать с описью 2-08.
- Остальные фото — быт, еда, кошки, кофе (атмосфера).

### `pharma` — справочник лекарств

- Поиск по названию (торговому и действующему веществу, без учёта регистра и «ё»), алфавитный список. Логотип — наверх; подвал — «О справочнике», «Правила», «Помощь».
- Карточка препарата: торговые названия, действующее вещество, фармакологическая группа, показания, **противопоказания**, побочные эффекты.
- 8–10 препаратов, все в одном формате; нужный ничем не выделен.
- **[Улика]** Пропранолол (торговое название Анаприлин): в противопоказаниях — бронхиальная астма; в побочных — бронхоспазм.
- Вымышленный «Седарин» оформлен так же, как настоящие.
- Внизу мелко: «Справочник создан для игры. Не используйте для лечения».

### `cloud` — облако погибшего

- Экран входа: логин (уже заполнен, неизменяем), поле пароля, кнопка «Войти». Неверный пароль — «Неверный пароль» без штрафа.
- После входа — жёлтая плашка: «Публикация по расписанию: **13.11.2026, 10:04**. Последнее подтверждение: 10.11.2026, 10:04». Таймер не тикает в реальном времени — показывается статично.
- Папки:
  - «Реестр» — таблица сделок «Закрытых вечеров» за 10 лет (дата, лот, покупатель, цена, комментарий), сортировка по колонкам. **[Улика]** Строка о табакерке Вольской с пометкой «З. знал, что копия».
  - «Переписка» — переписка Воронцова с Завьяловым в виде чата (ультиматум).
  - «Если вы это читаете» — обращение к тому, кто откроет архив.
  - «Для М.» — замок: «Папка защищена отдельным паролем» и кнопка «Ввести пароль» (окно: нужен отдельный пароль). Содержимое — только в развязке.
- Учётная запись в шапке открывает окно хранилища; подвал — «О сервисе», «Правила», «Помощь».
- Ссылки `{{ link('slug') }}` работают в письмах, репликах чата и ячейках таблиц (Markdown-формат `[текст](адрес)`); в письме «Если вы это читаете» можно сослаться на закрытую страницу.

### `video` — видео «репетиции»

- Карточка файла в стиле «Электронного дела»: «Изъято с телефона Волкова А. А.» (имя — из `characters`).
- Имя файла **[Улика: VID_20261108_141203.mp4]**, размер.
- Видеоплеер.
- Кнопка «Свойства файла»: дата создания **[Улика: 08.11.2026 14:12:03]**, модель устройства, длительность, разрешение.
- В видео за окном дневной свет — это часть съёмки, страница ничего не подсвечивает.
