# Шот-лист медиа: что снять или сгенерировать

Рабочий список для производства фото, аудио и видео. Чем генерировать и сколько это стоит — `docs/MEDIA-AI-OPTIONS.md`. Сюжетные требования к кадрам — в `docs/SCENARIO.md` → «Фото: шот-лист» (источник правды); здесь — к каждому кадру добавлены путь к файлу, технические требования и черновик запроса для генератора изображений. Если что-то здесь расходится со сценарием — прав сценарий.

## Как пользоваться

1. Снимите кадр или сгенерируйте его по запросу ниже. Для узнаваемых лиц генератору нужна **фотография-образец** человека (обычный снимок лица анфас при дневном свете); без образца генератор нарисует незнакомца.
2. Сохраните файл точно по пути из колонки «Файл» внутри папки `media/` (например, `media/portraits/kirill.jpg`).
3. Проверьте: `python -m engine build && python -m engine check`. Пропавшие файлы перечисляет `python -m engine release`.

**Общие технические требования:**
- фото — JPEG или WebP, не больше 300 КБ для ленты и портретов (до 1 МБ для улик, где важны детали); видео — MP4 (H.264 + AAC), **не больше 25 МБ**; аудио — MP3, 128 кбит/с;
- никаких настоящих логотипов, вывесок, гербов и узнаваемой символики — только вымышленные бренды из `content/world.yaml`; номера машин и документов — вымышленные;
- время и даты на кадрах — мира игры (октябрь–ноябрь 2026);
- **генерировать лица родственников** — только тех, кто не против; в семейной игре это сюрприз, поэтому лучше спросить мягко, не раскрывая сюжета («можно я сделаю тебе смешной портрет для семейной игры?»).

**Видео и голос лучше снимать вживую.** Генераторы плохо держат синхронизацию губ на минутном монологе и узнаваемость голоса. Монолог Волкова (40–60 с) и голос анонимного звонка надёжнее записать на телефон.
