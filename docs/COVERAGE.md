# Матрица покрытия: какой вопрос требует каждый материал

Составлено 28.10.2026 (сценарист, решение автора после второго прохождения): **игрок обязан пройти через все материалы этапа — документы, страницы, результаты лаборатории.** Это обеспечивают вопросы: обязательные (О), бонусные (Б) и финальные (Ф). Если материал не требовал ни один вопрос, добавлен контрольный вопрос (**К**, обязательный). На каждом этапе их не больше двух, где можно, это формы из нескольких полей. Финал — только выводы: лаборатория в финале закрыта, всё лабораторное требуют вопросы этапов 2–4.

Обозначения: «О s1.q1.time» — обязательный вопрос (поле формы); «осн.» — основание заявки в лабораторию; «пар.» — параметры заявки; «атм.» — атмосфера, отдельного вопроса не требует (почему, сказано в строке).
